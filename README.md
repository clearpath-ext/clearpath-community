## What's Here

This repo is the home for project-wide discussions that span multiple repositories:

- **[Discussions](https://github.com/clearpath-ext/clearpath-community/discussions)** — General questions, ideas, feedback, and community conversation
- **RFCs** — Proposals for significant new features or architecture changes (see `/rfcs`)
- **Roadmap** — Planned features and milestone tracking
- **Meeting notes** — Notes from community calls (when we hold them)

For bug reports or feature requests tied to specific repos, please use the issue trackers in those repos. This space is for broader conversation.

---

## RFCs (Request for Comments)

Large features go through an RFC process before implementation begins. This gives the community a chance to weigh in before significant work happens.

To propose an RFC:
1. Copy `rfcs/0000-template.md` to `rfcs/0000-your-feature-name.md`
2. Fill in the template
3. Open a PR — discussion happens in the PR comments
4. Once accepted, the RFC is merged and implementation can begin

## Community Guidelines

ClearPath is built for and with people who have disabilities. Our community must reflect that:

- **Presume competence** — never speak about disability in pitying or diminishing ways
- **Use inclusive language** — follow plain language principles even in technical discussions
- **Welcome all backgrounds** — SLPs, caregivers, AAC users, developers, designers are all equally valuable here
- **Be patient** — some contributors have communication differences; allow time and don't penalize non-standard communication styles

We follow the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org).
